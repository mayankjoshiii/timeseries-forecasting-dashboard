FEATURES AT A GLANCE:

Main Chart:
  - 730 days historical data + future forecast
  - Confidence intervals (80% & 95%)
  - 3 timeframe options (daily/weekly/monthly)

4 Forecasting Methods:
  - Moving Average (MA-7)
  - Exponential Smoothing
  - Holt-Winters
  - Linear Trend

Advanced Analytics:
  - Seasonal decomposition (trend/seasonal/residual)
  - Seasonality heatmap
  - Anomaly detection
  - Residual diagnostics

4 Datasets:
  - E-Commerce Revenue
  - Energy Consumption
  - Retail Foot Traffic
  - SaaS MRR Growth

Interactive Controls:
  - Forecast Horizon: 7-90 days
  - Confidence Level: 70-99%
  - Smoothing Factor: 0.1-0.9

KEYBOARD SHORTCUTS:
  - None (GUI-based, all controls visible)

TROUBLESHOOTING:

Charts not loading?
  → Check browser console (F12)
  → Ensure Plotly.js CDN is accessible
  → Try different browser (Chrome, Firefox)

Slow performance?
  → Modern browser required (Chrome 90+)
  → Check available RAM
  → Close other tabs

Mobile issues?
  → Fully responsive down to 480px
  → Charts may stack on small screens
  → Landscape mode recommended for tablets
